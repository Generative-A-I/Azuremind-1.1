# Azuremind-1.1
Act as a senior frontend engineer and UI architect. Build a highly professional, enterprise-grade AI chat interface using React, Tailwind CSS, and TypeScript. The application must look strictly corporate, utility-first, and clean—completely avoiding the "vibe-coded", overly rounded, flashy neo-brutalist or dark-mode-centric aesthetics popular in hobbyist AI apps. It should resemble a high-end enterprise dashboard (think AWS Console, Azure Portal, or Retool).1. Visual & UI Design RequirementsColor Scheme: Pure white background (#FFFFFF), light gray borders/panels (#F3F4F6 or #E5E7EB), charcoal text (#111827) for high contrast.Accent Color: Choose a sharp corporate accent color (e.g., Deep Cobalt Blue #2563EB or Emerald Green #059669). Use it sparingly for active states, primary buttons, and indicators.Typography & Spacing: Strict, high-density layout. Boxy design with minimal border radiuses (max 4px or 6px). Sharp borders, clear grids, and distinct utilitarian sections.Sidebar: Left-aligned panel for chat history, settings, and API configuration.Main Chat Window: Centered or full-width conversation area with a fixed bottom input bar.2. Branding & Core StateApp Name: "Azuremind Workspace"Model Display Name: Always display the model as "Azuremind 1.1" in the header and on model responses.Effort Selector: Provide a clean, native-looking dropdown or segmented control labeled "Effort Level".Effort Options: "Extra", "High", "Normal", "Low".Default Selection: "High".3. Progressive Web App (PWA) & Offline RequirementsPWA Assets: Provide the code and configuration for a standard manifest.json file including mandatory PWA properties (name, short_name, start_url, display: "standalone", theme_color, background_color, and icon arrays).Service Worker: Include a robust service-worker.ts (or sw.js) file that handles:Pre-caching of all core application shell assets (HTML, CSS, JS bundle).A Cache-First or Stale-While-Revalidate strategy for static resources.Network-Only strategy for the Groq API endpoints.PWA Lifecycle Management: In App.tsx or a dedicated register script, handle service worker registration, update detection (prompting the user when a new version is available), and offline/online status monitoring.Offline UX Banner: Include a clean, non-intrusive top banner or status indicator that appears immediately when the browser goes offline, informing the user that AI chat features require an active connection but historical chats remain viewable.Offline Data Persistence: Cache local chat history and the Groq API key securely in browser storage (localStorage or IndexedDB) so the application remains fully bootable and readable without an internet connection.4. Functional & Backend Logic (Groq API Integration)API Integration: Connect directly to the Groq Cloud API using standard fetch requests.Model Hardcoding: Under the hood, always route requests to a fast Llama-3 text model on Groq (e.g., llama-3.3-70b-versatile or llama3-8b-8192).API Key Management: Provide an input field in the sidebar for the user to paste their Groq API Key. Store it securely in browser storage.System Prompt Injector: Dynamically inject a system prompt based on the selected "Effort Level" to force the model to simulate that persona.5. Dynamic System Prompts to Inject"Extra" Effort: "You are Azuremind 1.1 running at Extra Effort capacity. You must show an extensive, step-by-step chain of thought reasoning process inside a <thinking> tag before delivering your final answer. Analyze the problem from 5 different angles.""High" Effort: "You are Azuremind 1.1 running at High Effort capacity. Provide a detailed, deep-thinking breakdown of your logic inside a <thinking> tag before giving your clear, structured response.""Normal" Effort: "You are Azuremind 1.1 running at Normal Effort capacity. Provide a brief, concise breakdown of your initial thoughts inside a <thinking> tag, then give a standard, direct answer.""Low" Effort: "You are Azuremind 1.1 running at Low Effort capacity. Do not overthink. Skip deep analysis. Provide a direct, immediate, and concise answer."6. Chat Interface FeaturesLoading State: Display a dedicated "Thinking..." loading state with a spinner when a stream/request is pending.Tag Parsing: Parse the custom <thinking> tags from the model's response. Render the thinking process inside a collapsible, light-gray accordion component labeled "Thinking Process" so the user can audit the model's "effort".Markdown: Support markdown rendering for the final answer.Deliver the complete, modular code structure across components: Sidebar.tsx, ChatArea.tsx, EffortSelector.tsx, OfflineBanner.tsx, manifest.json, service-worker.ts, and the main App.tsx coordinating the state, PWA initialization, and Groq API calls.
